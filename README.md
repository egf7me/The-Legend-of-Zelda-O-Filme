# Atividade: Desenvolvimento de Página Web - The Legend of Zelda: O Filme

## 📋 Descrição da Atividade

Esta atividade consistiu no desenvolvimento de uma página web estática contendo informações sobre o futuro filme "The Legend of Zelda", baseado na famosa série de videogames da Nintendo. O objetivo foi criar uma estrutura HTML semântica e organizada para apresentar dados técnicos e a sinopse do filme.

## 🎯 Objetivos da Atividade

- Aplicar conhecimentos de HTML para estruturar conteúdo web
- Utilizar tags semânticas apropriadas (header, main, section, figure, etc.)
- Organizar informações de forma clara e acessível
- Incluir elementos multimídia (imagens com legenda)
- Criar links para fontes de informação externas

## 📁 Estrutura do Projeto

```
thelegendofzelda.html
img/
    └── image.png (imagem do filme)
```

## 🛠️ Tecnologias Utilizadas

- HTML5
- Estrutura semântica
- Links externos
- Imagens com legendas

### Sinopse

O filme é uma adaptação da famosa série de videogames "The Legend of Zelda", criada pela Nintendo. A história segue Link, um jovem herói que embarca em uma jornada épica para salvar o reino de Hyrule das forças do mal lideradas pelo vilão Ganondorf. Com a ajuda da Princesa Zelda e de outros aliados, Link deve enfrentar desafios perigosos, resolver enigmas e lutar contra inimigos poderosos para restaurar a paz no reino.
